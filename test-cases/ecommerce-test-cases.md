# E-Commerce Test Cases

## Project Overview

This document contains sample functional and regression test cases for an e-commerce application.

## Test Case 001 – Add Product to Cart

**Test Case ID:** TC-ECO-001

**Module:** Product / Cart

**Test Scenario:** Verify that a user can add a product to the shopping cart.

### Preconditions

- User is on the product page.
- Product is available.

### Steps

1. Open the product page.
2. Select the required product configuration.
3. Click **Add to Cart**.
4. Open the shopping cart.

### Expected Result

The selected product should be added to the cart with the correct product name, quantity and price.

### Priority

High

### Test Type

Functional Testing
